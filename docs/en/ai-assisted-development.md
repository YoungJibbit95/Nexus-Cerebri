# AI-assisted open-source development
Nexus Cerebri is an MIT-licensed open-source project. Its scope is substantial, so development
also uses AI tools for boilerplate, bounded implementation tasks, review assistance, tests,
documentation and refactoring. Maintainers remain responsible for decisions and releases.

Generated or assisted code is not trusted by default. It must meet the same review, test,
safety, documentation and CI gates as every other contribution. A passing model explanation
is not evidence of correctness. Document assumptions, limitations and actual verification;
never invent test results, capabilities or benchmark numbers.

The learning path remains visible: explain concepts, compare alternatives and keep research
experiments separate from production. AI should support learning, not hide foundational
reasoning or substitute generated exercises for the maintainer's own research work.
Contributions should disclose material AI assistance in their description and identify what
was reviewed and verified. Do not submit secrets, private calendars or unlicensed source.
