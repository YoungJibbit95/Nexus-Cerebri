# Nexus Cerebri official site

`apps/cerebri-site` is the public static knowledge surface for Nexus Cerebri.

## Boundaries

- Repository Markdown remains canonical documentation.
- Cargo is the software-version authority; the current Master is the specification authority.
- Planner and temporal examples are generated by executing `cerebri-core` during the site build.
- TypeScript does not implement planner, validation, recurrence or execution semantics.
- Cerebri Lab remains a separate developer/research application.
- No provider execution, production authentication, durable ledger, learned preference system or neural inference is simulated.

## Commands

```sh
npm install
npm run check
npm run build
npm run test:e2e
npm run test:visual
```

From the repository root, `npm run docs:build` remains the canonical site build command and writes the ignored deployment artifact to `site/`.

The generator `scripts/build-site-data.mjs` runs before check/build, writes ignored typed generated modules, and copies the repository logo into the app's ignored static staging path.

## Static hosting

SvelteKit uses `@sveltejs/adapter-static`, prerenders public routes with trailing slashes and supports the GitHub Pages base path `/Nexus-Cerebri`. Runtime pages do not fetch GitHub or a CMS.

## Truth labels

Every significant explanatory visualization is labelled as:

- **REAL** — current repository fact or Rust-generated fixture output.
- **EDUCATIONAL** — an explanatory representation of documented architecture.
- **FUTURE CONCEPT** — intentionally not implemented.

The global depth selector changes the amount of explanation without changing system truth.
