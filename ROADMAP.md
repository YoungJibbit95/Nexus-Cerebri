# Nexus Cerebri Roadmap

Current detailed roadmap: `01_DEVELOPMENT_LEARNING_ROADMAP.md`.

The roadmap is target-based, not calendar-driven. Candidate software versions ship only when their acceptance criteria and Definition of Done are satisfied.

## 2026-09-19 status

Foundation bootstrap is implemented locally at workspace version 0.1.0 (unreleased):
typed CPIR, temporal/constraint primitives, deterministic grid planning, lifecycle,
mock execution contracts, REST/Node/Lab foundations, CI and paired reference docs.

Next milestone: Temporal Core, including bounded recurrence, free/busy and independent DST scenarios.
Advanced ML, learning, provider integration and production mutation remain deferred.
The detailed roadmap's January “CPIR v1” is a future target; the implemented schema is 0.1.
